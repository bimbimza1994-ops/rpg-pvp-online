# RPG PvP Online

## วิธีเปิดบนคอม
1. ติดตั้ง Node.js
2. เปิด Terminal ในโฟลเดอร์นี้
3. รัน `npm install`
4. รัน `npm start`
5. เปิด `http://localhost:3000`
6. เปิดหลายแท็บ/หลายเครื่องที่ URL เดียวกันเพื่อทดสอบผู้เล่นหลายคน

## หมายเหตุ
เป็นต้นแบบ Multiplayer: WebSocket server จัดการตำแหน่ง ผู้เล่น HP การโจมตี และการดรอปของ
ระบบ rarity ตามที่กำหนด: ของไม่ดี 10%, ของดี 10%, ของหายาก 20%, ตำนาน 60%.
การนำขึ้นอินเทอร์เน็ตจริงต้อง deploy Node.js server และใช้ HTTPS/WSS.
